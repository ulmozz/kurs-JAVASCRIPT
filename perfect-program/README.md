# Perfect Program

Niniejszy projekt dotyczy programu doskonałego, który posiada następujące cechy kodu:

* Kod czytelny dla pogramisty znającego język lub framework
* Nie wymaga pisania i czytania długiej dokumentacji, aby zrozumieć jego działanie
* Łatwy w utrzymaniu dla początkujących
* Dostatecznie wydajny z perspektywy użytkownika
* Pozbawiony widocznych błędów uniemożliwiających wykorzystanie
* W przypadku znanych błędów - zrozumiałe komunikaty dla użytkownika
* Wiadomo, gdzie wprowadzić zmianę
* Mała liczba zależności (możliwie bliska zeru)

Doskonały kod powinien być uzupełniony następującymi elemetami projektu:

* Obecny plik README, zawierający ogólny opis funkcjonalny i sposób użycia
* Log zmian jest zawarty w pliku CHANGELOG
* Sposób instalacji jest standardowy lub (lepiej) jego opis można znaleźć w pliku README
* Sposób uruchomienia jest standardowy lub istnieje wstępnie skonfigurowany skrypt uruchomieniowy, a sposób konfiguracji jest opisany w pliku README
* Posiada plik LICENSE definiujący zasady użycia
